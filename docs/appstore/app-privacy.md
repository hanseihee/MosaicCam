# 앱 개인정보(App Privacy) 항목 답안

App Store Connect → 앱 → 앱 개인정보 → "시작하기". API로는 못 넣는 항목이라 웹에서 아래대로 고른다.

## 데이터를 수집합니까?
**예** (에드몹 광고 SDK가 수집)

## 수집하는 데이터 유형
| 유형 | 세부 | 용도 | 사용자와 연결 | 추적에 사용 |
|---|---|---|---|---|
| 식별자 | 기기 ID | 제3자 광고 | 아니요 | **예** (ATT 허용 시 IDFA) |
| 위치 | 대략적 위치 | 제3자 광고 | 아니요 | 아니요 |
| 사용 데이터 | 광고 데이터 | 제3자 광고 | 아니요 | 아니요 |
| 사용 데이터 | 제품 상호작용 | 제3자 광고, 분석 | 아니요 | 아니요 |
| 진단 | 충돌 데이터, 성능 데이터, 기타 진단 데이터 | 분석 | 아니요 | 아니요 |

- 사진·사진 내용·연락처·이름·이메일·정확한 위치: 수집 안 함(모두 기기 안에서만 처리).
- 구매 내역: 수집 안 함(App Store가 처리하고 앱은 저장하지 않음).
- 근거: Google AdMob iOS 데이터 공개 안내 https://developers.google.com/admob/ios/privacy/app-store-data-disclosure

## 버전 페이지에서 함께 할 것
- "앱 내 구입 항목" → 광고 제거(realmasse.mosaiccam.removeads) 선택 → 저장
